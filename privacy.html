Privacy

This MVP is a browser-only application. Files selected in the tool are parsed and analyzed on the user's device and are not intentionally uploaded to an application backend.

No account is required. The “I’d use Pro” button stores a preference only in the current browser using localStorage.

The site may be hosted by a third-party static hosting provider, which can process standard web request metadata such as IP address and user agent under its own policies. If analytics, waitlists, payments, accounts or cloud processing are added, this notice must be updated before those features are enabled.

Draft for MVP validation; obtain appropriate legal review before commercial launch.
