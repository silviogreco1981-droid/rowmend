RRowMend

Privacy

RowMend is a local-first browser application. Files selected in the tool are parsed and analyzed on your device and are not intentionally uploaded to a RowMend application backend.

No account is required. Mapping profiles and transformation recipes are stored only in the current browser using localStorage until you delete them.

RowMend uses Umami Cloud for minimal usage analytics. The analytics integration may record page visits and fixed product interaction events such as loading a file or sample dataset, profiling a dataset, applying a transformation recipe, running a source-to-target comparison, generating INSERT or MERGE/UPSERT SQL, exporting a report or clean/error CSV file, saving a local profile or recipe, or opening the feedback form. Limited aggregate properties may be attached to an event, such as row and column counts, whether profiling or comparison found issues, aggregate row/column/issue counts, selected SQL dialect, file extension, transform operation names, recipe step counts, or fixed interaction context. RowMend does not send uploaded files, spreadsheet contents, file names, column names, record keys, generated SQL, target table names, profile or recipe names, or data values to Umami.

RowMend may invite you to provide voluntary product feedback through an embedded Tally form. The feedback integration does not send your uploaded files, spreadsheet contents, column names, generated SQL, target table names or validation results. RowMend may pass only a fixed interaction context such as whether the survey was opened after SQL generation, a clean CSV export, the Pro section or the footer. Any answers you submit in the form are sent to Tally and handled under Tally's own service and privacy terms.

The site may be hosted by a third-party static hosting provider, which can process standard web request metadata such as IP address and user agent under its own policies. Analytics is provided through Umami Cloud. If payments, accounts or cloud file processing are added, this notice must be updated before those features are enabled.

Draft for MVP validation; obtain appropriate legal review before commercial launch.
