Privacy

RowMend is a local-first browser application. Files selected in the tool are parsed and analyzed on your device and are not intentionally uploaded to a RowMend application backend.

No account is required. Mapping profiles, transformation recipes, data contracts, Local Projects and compact Workflow Runner history are stored only in the current browser using localStorage until you delete them.

RowMend uses Umami Cloud for minimal usage analytics. The analytics integration may record page visits and fixed product interaction events such as loading a file or sample dataset, profiling a dataset, applying a transformation recipe, creating or checking a local data contract, opening or updating a Local Project, starting or completing a local workflow run, running a source-to-target comparison, generating INSERT or MERGE/UPSERT SQL, exporting a report or clean/error CSV file, saving a local profile, recipe or contract, opening the feedback form, starting or completing the tutorial video, reaching fixed tutorial progress milestones, or clicking a demo, Pro-interest or founding-pilot call to action. Limited aggregate properties may be attached to an event, such as row and column counts, whether profiling, contract checking or comparison found issues, aggregate row/column/issue counts, selected SQL dialect, file extension, transform operation names, recipe step counts, contract rule counts, project artifact counts, aggregate workflow row/error counts, fixed interaction context, or campaign tags such as UTM source, medium and campaign when they are present in the landing URL. RowMend does not send uploaded files, spreadsheet contents, file names, column names, record keys, generated SQL, target table names, profile, recipe, contract or project names, or data values to Umami.

RowMend may invite you to provide voluntary product feedback or apply for a Founding Workflow Pilot through Tally forms. These integrations do not send your uploaded files, spreadsheet contents, column names, generated SQL, target table names or validation results. RowMend may pass only fixed interaction context or campaign tags. If you voluntarily apply for a pilot, information you enter such as work email, workflow type, approximate file size, problem description and preferred pilot scope is sent to Tally and used to evaluate and follow up on that request. Any information submitted through Tally is handled under Tally's own service and privacy terms.

The site may be hosted by a third-party static hosting provider, which can process standard web request metadata such as IP address and user agent under its own policies. Analytics is provided through Umami Cloud. Local Project exports can contain configuration metadata such as column names, mappings, contract rules and locally stored profile summaries, but they intentionally exclude source row data. Workflow Runner history stores compact summaries such as status, timestamp, duration and aggregate row/error counts, plus structural metrics used for local drift analysis: column names, inferred types, missing/uniqueness/mixed-type rates, completeness and duplicate counts. These history metrics remain in the current browser; RowMend does not store source rows, cell values, file names, SQL text or row-level validation detail in run history. If payments, accounts, project synchronization or cloud file processing are added, this notice must be updated before those features are enabled.

Draft for MVP validation; obtain appropriate legal review before commercial launch.
