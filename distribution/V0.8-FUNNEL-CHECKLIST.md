## Ratios

- Project creation rate = project_created / visits
- File-load rate = workflow_file_loaded / project_created
- Completion rate = workflow_run_completed / workflow_file_loaded
- Export rate = workflow_output_exported / workflow_run_completed

## Questions to answer

1. Which channel brings users who actually create projects?
2. Where does the largest funnel drop happen?
3. Are users reaching Workflow Runner?
4. Are runs completing?
5. Are completed runs producing exports?
6. Which errors or warnings appear most frequently?
7. Does qualitative feedback point toward Run Insights / Data Drift?
8. Is there any reason to change 0.9 scope before implementation?

## Deploy discipline

Until the current Netlify quota resets, do not consume a production deploy for:
- one copy change;
- one new guide;
- minor analytics refinement;
- cosmetic UI work;
- non-blocking refactors.

Bundle changes into the next substantial release candidate unless a blocking regression, privacy/security issue or critical product failure requires an emergency deploy.
