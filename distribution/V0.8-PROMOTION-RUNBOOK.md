# RowMend 0.8 promotion runbook

## Launch order

1. LinkedIn — personal founder post
2. Reddit / r/dataengineering — one transparent self-promotional discussion for the month
3. GitHub — repository announcement / README traffic
4. Search indexing — Google Search Console + Bing Webmaster Tools
5. Hacker News — only when the founder can write the actual Show HN text and replies personally
6. DEV — only as a genuinely human-authored technical article, not AI-generated promotional copy

## Why this order

LinkedIn and Reddit let us start collecting qualified external traffic quickly without waiting for search indexing. GitHub is already the natural technical proof point. Search submission should happen at the same time so the newly deployed guide pages enter the crawl queue.

Show HN should be treated as the highest-sensitivity launch: RowMend is now directly usable without signup, which fits Show HN well, but HN explicitly asks for human-written text and replies.

DEV also has explicit AI-assisted-content guidance. Do not post AI-generated promotional copy there.

## What to watch after each push

Primary funnel:

visit → project_created → workflow_file_loaded → workflow_run_completed → workflow_output_exported

Do not judge a channel by visits alone.

A channel with 30 relevant visitors and several completed workflows is more valuable than one with hundreds of passive visits.
