## Short description
Local-first CSV and Excel validation, mapping and safe SQL generation for database imports.

## Description
RowMend is a browser-based tool for validating CSV, TSV and Excel files before they are imported into a database.

It helps detect missing required values, duplicate keys, invalid values and mapping problems, separates clean and error rows, and generates INSERT plus MERGE/UPSERT SQL for Oracle, SQL Server and PostgreSQL.

Files are processed locally in the browser. No signup is required and uploaded spreadsheet data is not sent to a RowMend application backend.
