## Short description

Local-first CSV and Excel workflow runner for profiling, cleanup, data contracts, import validation, SQL generation and migration reconciliation.

## Longer description

RowMend helps developers, data engineers, analysts and operations teams make recurring CSV and Excel work repeatable.

Instead of rebuilding cleanup and validation for every delivery, users can keep an ordered cleanup recipe, data contract and import profile in a Local Project, then run a new file through:

Profile → Clean → Contract → Validate → Output

The tool also supports source-to-target migration checks and SQL generation for Oracle, SQL Server and PostgreSQL.

RowMend runs its data operations in the browser, requires no application account and does not intentionally upload source files to a RowMend backend.
