## Phase 3 — launch surface

### Product Hunt

Prepare the product draft now.

Product Hunt currently:
- accepts live digital products;
- recommends a simple non-marketing tagline;
- supports maker self-submission;
- recommends 240×240 thumbnail and 1270×760 gallery images;
- asks makers to request feedback, not upvotes;
- prohibits AI-generated comments.

Use genuine RowMend screenshots.

The maker first comment and replies must be written personally.

### Hacker News

Keep for a focused Show HN push after the Product Hunt/Reddit feedback has exposed obvious questions.

The Show HN text and all replies must be written personally, not generated or AI-edited.

## Channels intentionally skipped for now

### BetaList

Current submission is paid and requires the startup to use its own domain rather than a free hosting subdomain. RowMend currently uses rowmend.netlify.app, so skip it.

### SaaSHub

Current submission guidelines reject products using free subdomains such as *.netlify.app. Skip until RowMend has its own domain.

## Measurement rule

Do not change product strategy because of raw pageviews.

Meaningful signals:
- external users start the demo;
- external users create a project;
- external users load their own file;
- workflows complete;
- outputs are exported;
- feedback describes recurring-file pain;
- users return for a second run.

## Deploy rule

No production deploy for promotion-only tweaks. The known 0.8 Back to project overlap is already queued and fixed on the 0.9 branch.
