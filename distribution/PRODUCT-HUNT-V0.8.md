**Description**  
(max 500 characters)

RowMend is a local-first toolbox for recurring CSV and Excel work. Build a Local Project once, then run new files through profiling, cleanup recipes, data-contract checks, import validation and SQL preparation from one file load. It also includes source-to-target migration reconciliation. No account is required, and source data is processed in the browser rather than intentionally uploaded to a RowMend backend.
