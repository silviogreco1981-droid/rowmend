ROWMEND 0.9 · VIDEO TUTORIAL

See what changed before you trust the next delivery

A 71-second walkthrough of the RowMend workflow: establish a known-good baseline, load a changed recurring CSV delivery and use Run Insights to see the drift.

What the video shows

  1. Create the preconfigured monthly vendor import demo.
  2. Run a known-good delivery and establish a PASS baseline.
  3. Load the next delivery with intentional drift.
  4. Stop the workflow before unsafe output.
  5. Compare the two runs with Run Insights.
  6. Review row-count, completeness, duplicate and contract changes.
  7. Keep privacy-minimized local history without storing source rows.
