WHAT THIS CHECK PROVES

Reconcile the result, not just the row count.

A successful import can still hide missing records, unexpected additions, changed values or duplicate keys. Migration Check indexes source and target rows by the key you choose and compares mapped values without uploading the datasets.

Duplicate keys are reported as ambiguous instead of being silently matched. Normalization options affect comparison only; the original values are preserved in the review.
