PRIVACY BY ARCHITECTURE

Your spreadsheet is not our dataset.

RowMend is designed as a local-first toolbox. Profiling, cleaning, transformation recipes, validation, mapping, SQL generation and migration reconciliation happen in the browser. This MVP has no application backend and no account system.

Saved mappings and cleanup recipes remain in local browser storage until you delete them. Product analytics receives only aggregate interaction data, never uploaded file contents, file names, column names, record keys or data values.

FREE LOCALLY · PRO FOR TEAMS
