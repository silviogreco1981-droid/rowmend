Project portability

Exporting a project creates a JSON file with configuration and profile summaries. It intentionally excludes CSV/Excel row data, generated SQL and migration issue rows.

Delete this local project

This removes only the project container. Standalone recipes, contracts and import profiles remain in their existing local stores.

WHY PROJECTS

Move from one-off fixes to repeatable local operations.

The same monthly or weekly file usually needs the same cleanup, schema expectations, validation rules and downstream checks. Local Projects keeps those decisions together so the workflow is easier to repeat.

The future cloud/Team layer can build on this model with synchronized workspaces, history, schedules, permissions and audit trails — without taking away the free local project workflow.
